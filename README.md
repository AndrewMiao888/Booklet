# Small Things, Big Ocean

A responsive, 32-page interactive field guide to plastic pollution, microplastics, the Great Pacific Garbage Patch, bottled-water research and lower-waste habits.

## Stack

- Nuxt 4 and Vue 3 with TypeScript
- Tailwind CSS 4 through the official `@tailwindcss/vite` plugin
- Nuxt server rendering, with saved reading position and field notes restored client-side

Nuxt 4.6.3 is pinned by the dependency range as the current stable major. Nuxt 5 is still in prerelease, so this project stays on stable Nuxt 4.

## Run locally

Requires Node.js 22.12 or later.

```sh
npm install
npm run dev
```

Then open the local URL shown by Nuxt. Other available commands:

```sh
npm run typecheck
npm run build
npm run generate
npm run preview
```

## Explore

- Turn pages with the arrow buttons or keyboard arrows; jump with the contents list.
- Save your place and keep a small one-week action plan in browser storage.
- Explore the particle scale, bottle-volume calculator, credit-card myth check, gyre clue, reuse finder, laundry habits and recycling guide.
- Open the source shelf to read the linked research and public-health guidance.

## Evidence notes

The bottled-water page distinguishes the 2024 study’s average of about 240,000 nano- and microplastic particles per litre from its upper observations. The high-end figure of roughly 555,000 for a 1.5-litre bottle is a volume-scaled estimate; it is not a universal count, and most particles in that study were nanoplastics. The credit-card comparison is described as an uncertain 2019 estimate, not a measured personal weekly intake. Original research and guidance are linked in the reader and reference shelf.
